KASSIE'S PLACE WEBSITE

CONTENTS
- index.html          Home page
- products.html       Empty catalogue page (no products have been added)
- how-to-order.html   Ordering information
- about.html          Business information
- contact.html        Enquiry form that prepares a WhatsApp message
- assets/style.css    Shared responsive styling
- assets/site.js      Navigation and form behaviour

IMPORTANT SETUP BEFORE PUBLISHING
1. Open assets/site.js in a text editor.
2. Replace 1876XXXXXXXX with the real WhatsApp number, including country code 1 and digits only.
   Example format: 1876XXXXXXX (do not include +, spaces or hyphens).
3. Replace hello@example.com in the contact page and site settings if you want to show a real email.
4. Update the business story, address, hours, minimum order and delivery areas when those details are confirmed.
5. The contact form opens WhatsApp with a prepared message. The visitor must review and press Send.
6. No products have been added. The catalogue search is intentionally disabled until products are supplied.
7. The cart is not shown because there are no products to add. Once a product list is ready, cart and product search can be connected to it.

HOW TO PREVIEW
- Extract the ZIP file.
- Open index.html in a modern browser.
- For local development, you can also run a simple local web server from this folder:
  python3 -m http.server 8000
  Then visit http://localhost:8000

HOSTING
Upload the full folder contents to a static web host. Keep the assets folder alongside the HTML files.
